# 📸 Screenshots del Proyecto

Esta carpeta está destinada a almacenar las capturas de pantalla del proyecto para documentar visualmente su funcionamiento.

## Lista de Capturas Sugeridas

Por favor, toma las siguientes capturas y guárdalas en esta carpeta con los nombres indicados:

1.  **`panel-dashboard.png`**: Vista principal del Dashboard administrativo (CMS).
2.  **`panel-obras-editor.png`**: Vista del editor de obras en el CMS (formulario o lista).
3.  **`mapa-interactivo.png`**: Vista del mapa interactivo de México en el Frontend público.
4.  **`homepage.png`**: Vista completa o sección Hero de la página de inicio pública.
5.  **`obra-detalle.png`**: Vista de detalle de una obra individual en el Frontend.
6.  **`contacto.png`**: Vista de la página de contacto.

## Instrucciones

1.  Navega a la aplicación en tu navegador.
2.  Toma una captura de pantalla de la sección relevante.
3.  Renombra el archivo según la lista anterior.
4.  Mueve el archivo a esta carpeta `docs/screenshots/`.

Estas imágenes serán referenciadas automáticamente en el `README.md` principal si se sigue esta convención de nombres.
